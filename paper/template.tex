\section{Introduction}\label{sec:introduction}

Many of the most important questions in science, medicine, and industry are \emph{causal}: What happens to the outcome if we change the treatment, the price, the policy, or the process? Standard machine-learning models are built to answer a different question, namely what is likely to happen if nothing is changed. A model can predict outcomes very accurately and still be completely wrong about the consequences of an \emph{intervention}, because prediction exploits every correlation in the data, including correlations that would disappear the moment we intervene~\cite{pearl2009causality,hernan2020whatif}. Answering causal questions therefore requires dedicated methods, and those methods rest on \emph{assumptions} about how the data were generated.

This is where causal analysis becomes fragile in practice. Before seeing the answer, the analyst must choose a model class, an estimator, an adjustment strategy, and often more specialized ingredients such as how influence spreads through a network. Each choice is an assumption, and a wrong choice does not merely reduce accuracy; it can produce conclusions that are \emph{confidently wrong}. Two examples from our own benchmarks illustrate this. First, when a linear model is fitted to data generated by a single smooth nonlinear mechanism, it can ``discover'' a change in the causal mechanism that does not exist, while its test loss improves substantially; the better fit rewards the wrong structural conclusion. Second, when an unobserved common cause affects both treatment and outcome, a standard estimator can detect an effect in every run while its estimate is severely biased and its confidence interval never contains the truth. In both cases the analysis looks successful by the usual metrics and is wrong precisely where it matters.

The state of the art offers two partial answers, each with a gap. On one side, classical causal inference provides a rich theory of \emph{identification} (determining whether a causal question can be answered at all from the available data and assumptions), together with well-understood estimators~\cite{pearl2009causality,hernan2020whatif,hudgens2008interference}. But every new dataset requires the analyst to select and configure these tools by hand, and the examples above show how easily that selection goes wrong. On the other side, a recent line of work pretrains transformer models on large collections of synthetic causal problems, so that a new dataset can be analyzed in a single forward pass without refitting~\cite{ma2025causalfm,robertson2025dopfn,thompson2026arrow,qiao2026cdfm}. These \emph{causal foundation models} remove the manual selection burden, but they inherit a different risk: they \emph{always return an answer}, even when the question is not answerable from the data, thereby automating exactly the false confidence described above.

In this paper we propose the \textbf{Causal World Foundation Model (CWFM)}, a foundation model designed to combine the strengths of both sides. CWFM is a transformer pretrained on a large stream of synthetic causal problems. Given a new dataset together with a formally specified causal question, it answers \emph{in context}, without retraining. Two design choices distinguish it from prior causal foundation models. First, instead of acting as one universal neural estimator, CWFM learns to \emph{select and combine} a library of well-understood classical estimators, adding a learned correction only when it demonstrably \emph{does no harm}. Second, the model is wrapped in an explicit \emph{reliability layer}: a deterministic identification check and a data-support check decide, before any estimate is produced, whether the question can be answered at all. When it cannot, CWFM \emph{refuses} and explains why, instead of returning a misleading number. Its uncertainty intervals are \emph{calibrated} with finite-sample conformal methods rather than taken directly from the network.

The contributions of this paper are:
\begin{itemize}
\item the CWFM architecture, which integrates a pretrained causal encoder, a risk-routed library of classical estimators, formal identification and support gates, and \emph{calibrated abstention} in a single query-conditioned model;
\item a training and model-selection protocol in which safety requirements, such as never harming the classical estimate and never answering unanswerable queries, are enforced as \emph{hard constraints} rather than soft objectives;
\item a reproducible evaluation protocol with strictly separated training, development, calibration, and locked test streams, covering both answerable queries and stress queries that should be refused;
\item an open reference implementation of the model, the synthetic problem generators, and the complete experimental pipeline.
\end{itemize}

Our assessment is organized around five research questions:
\begin{itemize}
\item \textbf{RQ1} (\emph{accuracy}): Can a single pretrained model match well-tuned task-specific estimators on causal questions that are answerable from the data?
\item \textbf{RQ2} (\emph{safety}): Does the model avoid false causal claims when a question is not identifiable or not supported by the data?
\item \textbf{RQ3} (\emph{structure}): Can the model detect genuine changes in a causal mechanism while rejecting spurious changes induced by model misspecification?
\item \textbf{RQ4} (\emph{generalization}): How does the model behave on problem families that were held out from its pretraining distribution?
\item \textbf{RQ5} (\emph{attribution}): Which components of the architecture are actually responsible for the observed performance?
\end{itemize}

The experimental results can be summarized as follows. On answerable questions, CWFM matches the accuracy of the best task-specific estimator in each setting, without knowing in advance which setting it is in, and clearly outperforms a generic flexible baseline, with uncertainty intervals close to their nominal coverage (RQ1). It refuses every stress query that should be refused, while baseline estimators return a number in all of them (RQ2). It recovers genuine mechanism changes far more often than the previous version of the system and, unlike a standard model-based splitting baseline, largely resists the temptation to split a smooth nonlinear mechanism into fake regimes (RQ3). Generalization is good under moderate distribution shift but degrades sharply on one problem family that is qualitatively absent from pretraining, which we report as an honest limitation (RQ4). Finally, the gains are attributable to the estimator library, the risk-based routing, and the deterministic safety logic; the free-form neural components contribute little yet, which we also report openly (RQ5).

The remainder of the paper is organized as follows. Section~\ref{sec:related} reviews related work on causal inference and causal foundation models. Section~\ref{sec:preliminaries} introduces the necessary background concepts. Section~\ref{sec:approach} presents and motivates the CWFM architecture. Section~\ref{sec:assessment} describes the experimental design and answers the five research questions. Section~\ref{sec:discussion} discusses implications and limitations, and Section~\ref{sec:conclusion} concludes.

\section{Related Work}\label{sec:related}

\subsection{Causal Inference and Causal Discovery}\label{sec:related-causal}

Structural causal models and the potential-outcomes framework give causal questions a precise meaning~\cite{pearl2009causality,hernan2020whatif}. They distinguish three tasks that look similar but are fundamentally different: predicting an outcome under the observed regime, estimating the effect of an intervention, and reasoning about what would have happened in a particular case under a different action. Their central tool is the theory of \emph{identification}: a set of rules, such as back-door adjustment, that determine whether a causal question can be answered from the available data under stated assumptions. When point identification fails, the theory does not stop; sensitivity analysis quantifies how conclusions change as hidden confounding grows~\cite{rosenbaum1983sensitivity}, and partial identification replaces a point estimate with an honest interval~\cite{manski1990bounds}. The framework also covers settings where units influence one another, such as treatments that spill over through a network~\cite{hudgens2008interference}.

A complementary line of research, \emph{causal discovery}, aims to learn the causal structure itself from data. Approaches include constraint-based algorithms~\cite{spirtes2000causation}, continuous optimization over graph structures~\cite{zheng2018notears}, invariance of causal mechanisms across environments~\cite{peters2016invariant}, discovery from heterogeneous and nonstationary data~\cite{huang2020heterogeneous}, and causal analysis of nonlinear time series~\cite{runge2019pcmci}. All of these methods are powerful, but they share a practical burden: for every new dataset, an expert must choose the algorithm, the model class, and the tuning parameters, and the true structure is not available to check the choice. This manual selection step is exactly where the failures described in the introduction arise, and it is the entry point for foundation models.

\subsection{Foundation Models for Causal Tasks}\label{sec:related-cfm}

Prior-data fitted networks (PFNs) offer a way to remove the manual selection step. A transformer is pretrained on a large collection of synthetic problems whose ground truth is known by construction; afterwards, a new dataset is processed in a single forward pass, and the network approximates Bayesian inference under the distribution of problems it was trained on~\cite{muller2022pfns}. This idea has produced strong general-purpose tabular models~\cite{hollmann2025tabpfn} and has recently been carried over to causal questions. For causal-effect estimation, CausalFM builds PFNs from priors over structural causal models covering back-door, front-door, and instrumental-variable settings~\cite{ma2025causalfm}; Do-PFN predicts interventional outcome distributions directly from observational data~\cite{robertson2025dopfn}; and CausalPFN amortizes average and heterogeneous treatment-effect estimation~\cite{balazadeh2025causalpfn}. For causal discovery, Arrow predicts a graph skeleton together with a variable ordering, which guarantees an acyclic result~\cite{thompson2026arrow}; TabCausal and CDFM predict causal edges across heterogeneous tabular problems~\cite{li2026tabcausal,qiao2026cdfm}; and partial background knowledge can be supplied to such models instead of being ignored~\cite{reuter2026partialgraphs}. Extensions address temporal data with interventions~\cite{thumm2026causaltimeprior}, longitudinal treatment sequences~\cite{zare2026causallongpfn}, and amortized sensitivity analysis~\cite{javurek2026sensitivitypfn}.

These models establish that causal inference can be amortized, but two limitations recur. First, the synthetic pretraining distribution is itself a causal assumption: pretraining cannot make an unidentifiable question identifiable, and a dataset generated by a mechanism outside the prior can be answered with unwarranted confidence. Second, and most importantly for this paper, these models \emph{always return an answer}. None of them combines amortized estimation with a formal check of whether the submitted question is answerable at all, a check of whether the requested contrast is supported by the data, and the option to refuse.

\subsection{Reliability, Calibration, and Abstention}\label{sec:related-reliability}

The ingredients for such checks exist, but largely outside the foundation-model literature. Identifiability is a property of the causal model and its assumptions, not a pattern that can be certified from the data alone; learned ``identifiability scores'' are therefore heuristics that reflect the training prior, and even amortized sensitivity analysis can only learn the bounds of a partially identified effect, never its exact position inside them~\cite{ma2025causalfm,javurek2026sensitivitypfn}. When no ground truth is available, self-compatibility checks can falsify a causal analysis by testing whether structures learned from different subsets of variables agree~\cite{faller2024selfcompatibility}. On the uncertainty side, conformal prediction turns any point predictor into intervals with finite-sample validity guarantees~\cite{vovk2005conformal,lei2018distribution}, and selective prediction studies the trade-off between answering fewer questions and answering them more reliably~\cite{geifman2017selective}. Each of these tools is well understood in isolation; what is missing is their integration into an amortized causal model, so that identification, support, calibration, and refusal are produced together with the estimate rather than left to the analyst.

\subsection{Positioning and Research Gap}\label{sec:related-gap}

In summary, two research traditions approach causal questions from opposite directions. Classical causal inference is identification-aware and statistically rigorous, but every analysis must be assembled by hand, and the required choices are error-prone. Causal foundation models remove the manual effort through pretraining, but they answer unconditionally and provide no built-in notion of when an answer is unjustified. CWFM is positioned at the intersection of the two: it uses a pretrained model to amortize the choice and combination of estimators, while a deterministic identification layer, a query-specific support check, conformal calibration, and an explicit abstention decision guarantee that the convenience of a foundation model does not come at the price of false causal confidence. To our knowledge, no existing causal foundation model treats refusal as a first-class output and enforces it as a hard constraint during model selection.

\section{Preliminaries}\label{sec:preliminaries}

This section introduces the four concepts needed to follow the rest of the paper. Readers familiar with causal inference may skip to Section~\ref{sec:approach}.

\subsection{Structural Causal Models, Interventions, and Identification}\label{sec:prelim-scm}

A \emph{structural causal model} (SCM) describes a system as a set of variables, each generated by a mechanism from its direct causes plus independent noise~\cite{pearl2009causality}. As a running example, suppose a variable $X$ (say, the severity of a patient's condition) influences both a treatment decision $A$ and an outcome $Y$, and the treatment also influences the outcome. An \emph{intervention} replaces one mechanism by force: instead of letting doctors choose the treatment, we set it to a fixed value $a$, written $do(A=a)$. The canonical causal quantity in this paper is the \emph{average treatment effect} (ATE),
\begin{equation}
\tau \;=\; \mathbb{E}\!\left[Y \mid do(A=1)\right] \;-\; \mathbb{E}\!\left[Y \mid do(A=0)\right],
\end{equation}
the expected change in the outcome if everyone were treated versus no one. The difficulty is that we only observe data from the system \emph{without} the intervention: sicker patients are treated more often, so simply comparing treated and untreated outcomes mixes the effect of the treatment with the effect of severity.

\emph{Identification} asks whether a causal quantity can, in principle, be computed from the observed data under stated assumptions. In the example, if all common causes of $A$ and $Y$ are observed (here, $X$), the ATE is identified by the \emph{back-door adjustment} formula: compare treated and untreated outcomes within each level of $X$, then average over the population. Estimating this formula by fitting a regression of $Y$ on $A$ and $X$ and averaging its predictions is called \emph{g-computation}; it is one of the classical estimators our model builds on. If, however, some common cause is unobserved (\emph{hidden confounding}), no amount of data from the same source recovers the ATE: the question is \emph{not identified}, and an honest analysis must say so, widen its answer to a range, or state which additional assumptions would be needed.

\subsection{Network Interference and Exposure Mappings}\label{sec:prelim-interference}

Classical causal inference assumes that treating one unit does not affect another. In many settings this is false: vaccinating my neighbors protects me, and a promotion in one store draws customers from nearby stores. This phenomenon is called \emph{interference}, and its analysis requires knowing which units are connected, typically given as a network over the units~\cite{hudgens2008interference}. Because a unit can be affected by many neighbors in many ways, one summarizes the treatments of its neighbors by an \emph{exposure mapping}, for example ``the fraction of my neighbors that are treated.'' A typical causal quantity is then a \emph{spillover effect}: the expected change in my outcome if my neighbors' exposure moved from a low to a high level while my own treatment stayed fixed.

Two practical conditions matter throughout this paper. First, the exposure mapping is an assumption; if influence actually depends on, say, edge weights or two-hop neighbors, an analysis based on the simple fraction can be biased. Second, the requested contrast must have \emph{overlap} (also called positivity): there must exist comparable units observed at both exposure levels. If nobody in the data ever had a highly treated neighborhood, no method can estimate what would happen in one, and the only correct answer is to refuse.

\subsection{Regimes and Mechanism Changes}\label{sec:prelim-regimes}

Real systems are often not governed by one mechanism. The relation between inputs and outcome may differ across subpopulations, for example below and above a threshold of some observed variable: a machine behaves differently past a temperature limit, a subsidy rule changes at an income cutoff. We call such mechanism differences \emph{regimes}, and \emph{regime determination} is the task of deciding whether the data were generated by one mechanism or several, and if several, which variable and threshold separate them.

The task hides a trap that plays a central role in this paper. A single smooth nonlinear mechanism can be approximated surprisingly well by two linear pieces. A procedure that fits linear models and searches for splits will therefore ``find'' a regime boundary in perfectly stationary nonlinear data, and its predictive accuracy will genuinely improve. The improvement is real; the structural conclusion is false. Deciding between ``one curved mechanism'' and ``two straight ones'' therefore requires more than predictive gain, which is why regime determination is treated as a structural question, separate from prediction, throughout this work.

\subsection{Amortized Inference and Conformal Calibration}\label{sec:prelim-amortized}

Traditionally, every new dataset requires selecting and fitting a new statistical model. \emph{Amortized inference} moves this cost to a single pretraining phase: a neural network is trained on a very large collection of synthetic problems whose true answers are known by construction, and it learns to map a dataset directly to an answer~\cite{muller2022pfns}. At deployment, a new dataset is simply fed to the network, which answers \emph{in context}, in one forward pass, without any refitting. The strength of this approach is that the network has effectively seen millions of analyses; its weakness is that everything it knows comes from the distribution of synthetic problems it was trained on, so that distribution acts as a prior and is part of the model's assumptions.

A learned network also outputs uncertainty, but a neural confidence value carries no guarantee. \emph{Split-conformal prediction} provides one~\cite{vovk2005conformal,lei2018distribution}. The idea takes three sentences: hold out a set of calibration problems the model has never used for training; record how wrong the model was on each; then widen the model's intervals on new problems until they cover the observed error distribution at the desired level, for example 90\%. Under mild conditions this yields intervals with a finite-sample validity guarantee, which is why, in this paper, all reported uncertainty comes from conformal calibration rather than from the network's raw confidence.

\section{Approach}\label{sec:approach}

CWFM takes a dataset together with a formal causal question and returns either a calibrated causal answer or an explicit, explained refusal. This section presents the architecture step by step. Every component exists to prevent one of the failures described in the introduction, and we state this motivation as each component is introduced.

\subsection{Design Principles and Overview}\label{sec:approach-overview}

Four principles shape the design.

\begin{enumerate}
\item \emph{Amortize the choice of method, not the method itself.} The model learns to select and combine well-understood classical estimators. It does not replace them with a free-form neural predictor.
\item \emph{A learned component must never silently degrade a sound classical result.} Neural corrections are allowed only where they demonstrably help; when in doubt, the classical estimate stands.
\item \emph{Decide whether the question is answerable before trying to answer it.} This decision is made by deterministic logic, not by the network.
\item \emph{Report only uncertainty that carries a guarantee, and refuse rather than guess.} Intervals come from conformal calibration; unanswerable questions receive a refusal, never a number.
\end{enumerate}

Figure~\ref{fig:architecture} shows how these principles translate into a pipeline. The input is a \emph{causal episode} (the data plus everything known about it) and a formal query (Section~\ref{sec:approach-episode}). A typed encoder turns the episode into internal representations (Section~\ref{sec:approach-encoder}), from which structural heads propose hypotheses about the underlying causal structure (Section~\ref{sec:approach-worlds}). Before any estimation, two gates check whether the query is identifiable and supported by the data; if not, the pipeline exits with a structured refusal (Section~\ref{sec:approach-gates}). If the gates pass, a library of classical estimators produces the answer, weighted by a learned router and adjusted, at most slightly, by a gated neural correction (Section~\ref{sec:approach-estimation}). Finally, conformal calibration turns the answer into an interval with a coverage guarantee (Section~\ref{sec:approach-calibration}). Section~\ref{sec:approach-data} describes the data on which the model is trained and tested, and Section~\ref{sec:approach-training} explains how the system is pretrained on those data and how safety is enforced during model selection.

\subsection{Causal Episodes and the Formal Query Language}\label{sec:approach-episode}

The input unit of CWFM is a \emph{causal episode}: the dataset together with everything relevant that is known about it. Concretely, an episode contains the observed values, indicators of which values are missing, a schema stating the type of each variable (continuous, binary, and so on), the role of each variable with respect to the question (treatment, outcome, or covariate), an optional relation matrix connecting the units when interference is possible, and declared design knowledge, for example that the treatment was randomized. Passing this context explicitly matters: whether an analysis is valid often depends less on the numbers than on how they were produced.

The question itself is a \emph{formal query}, a small structured object stating the claim type (associational or interventional), the treatment and outcome variables, the causal quantity requested (for example the ATE, or a spillover contrast between two exposure levels), and the target population. We insist on a formal query rather than a natural-language question for two reasons. First, small changes of wording must not silently change the quantity being estimated; the formal object makes the estimand explicit and fixed. Second, the claim type prevents a quiet upgrade of an associational finding into a causal one: an interventional answer can only be produced for a query that requested one and passed the gates. A language model may translate a scientist's question into this format, but the causal core operates on the structured object only.

\subsection{Typed Encoder and Mechanism Experts}\label{sec:approach-encoder}

The encoder converts an episode into internal representations. Each cell of the data table is embedded from its value, its missingness indicator, the type of its variable, and the role of its variable in the query. There is deliberately no embedding of the column position: the meaning of a variable comes from its role and type, not from being column four, and permuting the columns of the input should permute the output accordingly.

Attention, the basic operation of transformer models by which each part of the input gathers information from related parts, then alternates along two axes. Attention across variables, within one sample, lets the model relate treatment, outcome, and covariates to one another. Attention across samples, within one variable, lets it see distributional patterns such as skewness, subgroup structure, or outliers. When the episode contains a relation matrix, an additional message-passing step lets each unit see summaries of its neighbors, which is what a spillover analysis needs.

The feed-forward layers are organized as a sparse \emph{mixture of mechanism experts}. Instead of one universal network, several small expert networks specialize in different mechanism families, and a learned router activates only the most relevant ones for each episode. The router carries a simplicity prior: flexible experts are used only when the data demand them. The motivation comes directly from our benchmarks, where a simple linear method beats a flexible one when the truth is linear, and the flexible method wins when the truth has a threshold. A model with a single, uniformly flexible pathway tends to blur exactly this distinction.

\subsection{A Posterior over Causal Worlds}\label{sec:approach-worlds}

A standard pipeline commits early to one causal structure and then treats it as true. CWFM instead maintains a small set of weighted \emph{world particles}. Each particle is one coherent hypothesis about the data-generating process: a graph over the variables, a mechanism family, and a regime hypothesis. The weights express how plausible each world is given the episode, so together the particles form an approximate posterior distribution over causal worlds; this gives the model its name. Maintaining several worlds separates two kinds of uncertainty that a single confidence interval would wrongly merge: uncertainty about \emph{which structure} generated the data, and uncertainty about \emph{parameter values} within a structure.

Structural decoders read these representations and output probabilities rather than hard decisions. The regime decoder is hierarchical and mirrors how an analyst would reason: first, is there evidence of a mechanism change at all; if so, which variable separates the regimes; at which threshold; and what kind of change it is. Because the stationary nonlinear trap of Section~\ref{sec:prelim-regimes} is the known failure mode here, the decoder is trained on matched pairs of episodes in which one curved mechanism and two straight ones look predictively similar but differ structurally, so that predictive gain alone never triggers a split.

\subsection{Identification and Support Gates}\label{sec:approach-gates}

Before any estimate is produced, two gates decide whether the query should be answered at all.

The \emph{identification gate} checks whether the requested causal quantity is identified given the episode's declared assumptions and design knowledge, for example randomized assignment or the assumption that all relevant confounders are observed. This gate is deterministic logic, not a learned component, for a principled reason: identifiability is a property of the causal model and its assumptions, and it cannot be certified from data patterns alone. A learned score could only imitate the training prior and would produce exactly the confident wrong answers we aim to prevent. This gate is the direct response to the hidden-confounding failure of the introduction, where a conventional method detected an effect in every run while its estimate was severely biased.

The \emph{support gate} checks whether the requested contrast is present in the data: are there comparable units observed under both treatment values, or both exposure levels, for the population in the query? If nobody in the data resembles the requested condition, any estimate would be extrapolation from the pretraining prior rather than evidence, and the gate blocks it.

When either gate fails, CWFM returns a \emph{structured refusal} that names the failed condition and what would resolve it, for example an instrument, an experiment, or additional data in the unsupported region. Learned diagnostic heads accompany the gates with empirical signals such as estimated overlap and prior mismatch, but they can only add caution; they can never overrule a formal gate and force an answer.

\subsection{A Risk-Routed Library of Classical Estimators}\label{sec:approach-estimation}

When both gates pass, the answer is produced by classical statistics guided by the learned model, in three steps.

First, every member of a \emph{library of estimators} is applied to the episode's data, each producing its own candidate estimate. Each member is a standard, well-understood method that is correct under a different mechanism class: linear g-computation, g-computation with interactions, a spline-based version, a piecewise exposure-response estimator for threshold spillovers, a design-based estimator for randomized episodes, and a null estimator that returns no effect. Internal regression fits use held-out folds (held-out clusters in network episodes), so that no observation contributes to a prediction about itself.

Second, a learned \emph{router} predicts, from the episode representation, how risky each estimator is for this particular episode, and combines the library into a single weighted estimate. We call this the \emph{compiled estimate}. It is the answer classical statistics would give if an experienced analyst had chosen and blended the estimators; the router amortizes that choice.

Third, a neural \emph{residual} may adjust the compiled estimate. It is initialized at zero, passes through a learned gate, and is trained with a no-harm objective that penalizes any adjustment that worsens the compiled estimate far more than it rewards an improvement. If the residual cannot prove its worth during training, the gate stays closed and the final answer equals the compiled estimate. This is the architectural embodiment of principle 2: the burden of proof is on the neural correction, never on the classical estimate.

\subsection{Calibration}\label{sec:approach-calibration}

All reported uncertainty comes from split-conformal calibration (Section~\ref{sec:prelim-amortized}). A dedicated bank of calibration episodes, never used for training, records how wrong the model's answers are in practice; intervals on new episodes are then widened until they cover this error distribution at the target level. The conformal scores are normalized and stratified, so intervals adapt to episode difficulty: an episode routed to a risky estimator, or one where the estimators disagree, receives a wider interval. The threshold at which the regime decoder declares a mechanism change is fitted on the same calibration bank rather than learned end to end, for the same reason: a decision with error-rate consequences should be set where its error rate can be measured.

\subsection{Training and Evaluation Data}\label{sec:approach-data}

The data deserve particular attention, because for a pretrained causal model the training distribution is not an implementation detail: it is part of the model's assumptions. Everything CWFM knows, it knows from this distribution. We therefore describe it precisely.

All training and evaluation data are \emph{synthetic causal episodes} produced by a simulator, and this is a necessity rather than a convenience. Supervising a causal model requires labels that real data cannot provide: the true effect of an intervention, the true causal structure, and the true answer to the question ``should this query be refused?''. In a simulation these labels are known by construction. Each episode is created in three steps: first a complete causal world is sampled (a graph, mechanisms, an assignment process, and an effect size); then the world is run to produce an observed dataset; finally the ground-truth labels are recorded and hidden from the model, which must recover them from the data alone.

Episodes come from three task families, matching the implemented scope:
\begin{itemize}
\item \emph{Static treatment effects.} Between 64 and 128 units are described by three to eight covariates; a binary treatment affects a continuous outcome. Scenarios include linear and nonlinear mechanisms with observed confounding, and randomized experiments.
\item \emph{Regime determination.} Datasets with five to nine covariates whose outcome mechanism either is stationary, splits at a threshold of one covariate (with strong or deliberately weak shifts), or is a stationary smooth nonlinear mechanism, the hard negative of Section~\ref{sec:prelim-regimes}. Exact nulls are always included.
\item \emph{Network interference.} Units are linked by a cluster-structured network and treated cluster by cluster with varying saturation; each unit's exposure is the treated fraction of its neighbors. Spillover mechanisms are linear, threshold-shaped, or exactly null.
\end{itemize}
Crucially, every family also generates \emph{unanswerable episodes} in which the correct output is a refusal: hidden confounding (an unobserved variable drives both treatment and outcome) and poor overlap or poor support (the requested contrast barely occurs in the data). These cases are mixed into training at substantial rates. A model never shown them would learn that producing an answer is always rewarded, which is precisely the behavior we must avoid.

To prevent the model from learning superficial shortcuts, the presentation of every training episode is randomized: rows are shuffled, columns are permuted while preserving their declared roles, covariate scales are varied, and a random subset of covariate values (up to five percent) is masked as missing. The model must therefore rely on the declared roles and types of variables, never on their position or scale.

Training and evaluation use five strictly separated streams, drawn from disjoint random-seed ranges so that no episode can appear in more than one stream. Table~\ref{tab:streams} summarizes them. Training episodes are generated online and never repeated: over 1,600 steps with 24 episodes per batch, the model sees 38,400 distinct episodes exactly once each. The final test bank is \emph{locked}: it is evaluated once, after all training, selection, and calibration decisions are frozen, and its 14 scenario cells with 30 seeds each are identical for CWFM and for every baseline.

The out-of-distribution development bank deserves a separate remark. Holding out whole families, rather than merely new random draws from familiar ones, is what allows Section~\ref{sec:assessment} to distinguish genuine generalization from memorization of the training prior.

\subsection{Pretraining and Safety-Constrained Model Selection}\label{sec:approach-training}

CWFM is pretrained on the online episode stream of Section~\ref{sec:approach-data}, and training proceeds in stages. The estimator library and the router are trained first, with the residual frozen, so that a sound compiled path exists before any neural correction is allowed. The gated residual is then trained under the no-harm objective, and finally the whole system is fine-tuned jointly at a low learning rate.

Model selection enforces safety as \emph{hard constraints}, not as terms in a loss. A checkpoint is eligible only if it does not materially harm the compiled estimate, keeps the false-regime rate on stationary nonlinear episodes below a cap, and produces zero answers on queries that should be refused. Only the eligible checkpoints are then ranked, by their worst-group error on held-out mechanism families. A checkpoint with better average accuracy that violates any safety constraint is discarded. This ordering, safety first and accuracy second, is deliberate: it prevents the selection process itself from trading reliability for benchmark scores.

Finally, we state the implemented scope explicitly. The reference implementation covers static tabular effects, observed-regime determination, and network interference. Temporal mechanism changes, latent-variable structure, and identification with partially specified graphs are part of the design but not of the implementation evaluated in Section~\ref{sec:assessment}, and no claim in this paper depends on them.

\section{Assessment}\label{sec:assessment}

This section first describes the experimental design and then answers the five research questions of the introduction, one subsection each.

\subsection{Experimental Design}\label{sec:assessment-design}

All results below come from the locked final test bank of Section~\ref{sec:approach-data}, which is evaluated exactly once, after every training, selection, and calibration decision is frozen. The bank contains 14 scenario cells with 30 seeds each, identical for all methods. Six cells contain answerable effect queries (static linear, static nonlinear, and randomized treatment effects; linear, threshold, and null network spillovers), giving 180 queries in which the true effect is known and an estimate is expected. Four cells contain regime-determination problems (a strong split, a weak split, the stationary nonlinear hard negative, and a complete null). The remaining four cells are \emph{stress cells} with 120 queries that must be refused: hidden confounding and poor overlap in the static setting, and hidden confounding and poor support in the network setting.

CWFM is compared against five baselines that always answer: linear g-computation, g-computation with interactions, spline g-computation, a piecewise exposure-response estimator, and random forest g-computation. Each baseline is a strong specialist for at least one cell, so the comparison is deliberately unfavorable to a general model. For regime determination, the baseline is a model-based recursive splitting procedure of the kind widely used in practice. We also report \emph{CWFM (compiled only)}, which is the full system with the neural residual removed; the difference between the two isolates the contribution of the learned correction in RQ5.

Metrics are the mean absolute error (MAE) of the estimated effect against the known truth, the empirical coverage and width of the 90\% intervals, the rate of false answers on the stress cells, and exact accuracy for regime determination (the detected structure must match the truth, including detecting nothing when there is nothing). Differences between methods are assessed with paired bootstrap confidence intervals over the shared seeds. All seeds, configuration values, and package versions are recorded in a result manifest together with a cryptographic hash of the evaluated checkpoint, so the experiment can be reproduced exactly.

\subsection{RQ1: Accuracy on Answerable Queries}\label{sec:assessment-rq1}

\emph{Answer: yes. Without knowing which setting it is in, CWFM matches the best specialist estimators and clearly outperforms the flexible generic baseline, with intervals close to nominal coverage.}

Figure~\ref{fig:rq1} shows the pooled picture over the 180 answerable queries. CWFM reaches a pooled MAE of 0.166, side by side with the two best specialists (interaction g-computation at 0.167 and linear g-computation at 0.169) and far ahead of random forest g-computation at 0.329. The paired differences confirm statistical equivalence with the specialists: CWFM versus linear g-computation is $-0.0028$ with a 95\% bootstrap interval of $[-0.0132, 0.0080]$, and versus interaction g-computation $-0.0003$ with $[-0.0111, 0.0109]$. Versus random forest the difference is $-0.163$ with $[-0.203, -0.122]$, a clear improvement. Coverage of the 90\% intervals is 0.906, and the mean interval width (0.793) is in the same range as the specialists (0.772 to 0.817) and far below random forest (1.337).

\subsection{RQ2: Safety on Unanswerable Queries}\label{sec:assessment-rq2}

\emph{Answer: yes. CWFM answered all 180 answerable queries and refused all 120 queries that should be refused, a false-answer rate of zero. Every baseline returned a number in every stress cell.}

The stress cells are the queries where a number is a mistake: hidden confounding makes the effect unidentifiable, and poor overlap or support means the requested contrast barely occurs in the data. The always-answer baselines produce estimates in all of them, and those estimates inherit exactly the failure described in the introduction: they can look precise while being systematically wrong. CWFM instead returns a structured refusal naming the failed condition.

Transparency requires stating where this guarantee comes from. The refusals are produced by the deterministic identification and support gates operating on the episode's declared design information, not by a neural network discovering hidden confounding in the data; the learned heads contribute empirical diagnostics only. The correct reading of this result is therefore architectural: routing every query through formal gates makes false causal claims impossible \emph{by construction} for declared conditions, and the experiment confirms that the surrounding learned machinery never circumvents the gates. Detecting undeclared identification failures from data alone remains an open problem for any method.

\subsection{RQ3: Regime Detection without False Splits}\label{sec:assessment-rq3}

\emph{Answer: largely yes. CWFM recovers most strong regime splits while rejecting most spurious ones, where the standard splitting baseline is fooled every time; weak splits remain out of reach for both.}

Table~\ref{tab:regime} compares CWFM with the recursive splitting baseline. On strong splits the baseline is more sensitive (exact accuracy 0.800 versus 0.633). The decisive difference is the stationary nonlinear hard negative: the baseline declares a split in 100\% of these episodes, mistaking one curved mechanism for two regimes in every single run, while CWFM declares a split in only 16.7\% and identifies the correct stationary structure in 83.3\%. Both methods are essentially perfect on the complete null, and both fail on the deliberately weak splits, whose signal is simply too small at this sample size. Pooled over all four cells, CWFM reaches 0.617 exact accuracy versus 0.458 for the baseline. The trade of some sensitivity for a large gain in structural specificity is intentional and follows from the calibrated decision threshold of Section~\ref{sec:approach-calibration}.

\subsection{RQ4: Generalization to Held-Out Families}\label{sec:assessment-rq4}

\emph{Answer: mixed, and we report it as measured. Accuracy transfers well to most held-out families but fails on the one family that is qualitatively unlike anything in training.}

Figure~\ref{fig:rq4} shows effect MAE on the six mechanism and graph families that were entirely excluded from training. On hinge outcomes, multiplicative outcomes, and the unfamiliar Erd\H{o}s-R\'enyi random graphs, error stays essentially at the in-distribution level. Saturating outcomes and small-world graphs roughly double it, which is a moderate and arguably acceptable degradation. Nonmonotone interference, however, fails badly, with an MAE of 1.357, roughly eight times the in-distribution level: spillovers that first rise and then fall resemble nothing in the training distribution, and the model has no basis for them.

\subsection{RQ5: Where Do the Gains Come From?}\label{sec:assessment-rq5}

\emph{Answer: from the classical estimator library, the risk-based routing, and the deterministic safety logic. The free-form neural components contribute little yet, and we report this openly.}

The cleanest evidence is the comparison with CWFM (compiled only): the two systems produce point estimates that are equal to numerical precision. The gated neural residual remains almost closed (mean gate activation 0.0067) and its mean absolute correction is below $3\times10^{-8}$, so the no-harm training of Section~\ref{sec:approach-estimation} did exactly what it was designed to do, and no more: the residual never damaged the compiled estimate, and it also never improved it. Similarly, the posterior over causal worlds remained effectively uniform across its particles in this run, so the world machinery, while architecturally in place, did not yet contribute measurable value. We consider reporting these honest negatives more useful than hiding them behind aggregate scores.

Routing works but is not sharp. All six estimator experts stay in use, yet in threshold spillover episodes the router assigns the piecewise expert only about 15\% of the weight although that expert is clearly the best there (Table~\ref{tab:scenario}: 0.173 versus 0.283 for CWFM's blend). Sharper episode-level risk prediction is the most direct path to improvement, and Table~\ref{tab:scenario} bounds the available headroom.

Finally, Table~\ref{tab:probes} reports invariance probes: the estimate should not change when the data are presented differently. Row shuffling and affine rescaling of the outcome change the estimate only at numerical noise level. Inserting an irrelevant covariate shifts it moderately, and reordering columns (with roles preserved) shifts it most, so full variable-order equivariance is not yet achieved despite the randomized training presentation. Together with the diffuse routing and the inactive world posterior, these probes give the next revision of the system a concrete and measurable agenda.

\section{Discussion}\label{sec:discussion}

\subsection{What the Results Mean}\label{sec:discussion-meaning}

The results support a specific, and perhaps sobering, reading of what a foundation model for causal inference should be. The measured gains did not come from a neural network that estimates effects better than classical statistics. They came from three less glamorous ingredients: a library of classical estimators applied correctly, a learned router that amortizes the choice among them, and deterministic safety logic that decides when no estimate should be produced at all. In other words, the foundation-model machinery earned its place by \emph{selecting and guarding} classical inference, not by replacing it.

We believe this is the realistic near-term value of the approach. Matching a correctly chosen specialist is of limited interest when the specialist is known; the practical problem is that in real analyses nobody tells the analyst which specialist is correct, and Table~\ref{tab:scenario} shows how costly a wrong choice is. A single model that is close to the winner in every cell, refuses the queries that should be refused, and reports calibrated intervals removes exactly the decisions that make applied causal analysis fragile. The zero false-answer rate deserves emphasis for a second reason: it was achieved by construction and verified by experiment, an ordering we consider healthier than hoping that a learned system happens to behave safely.

The safety-first selection protocol also deserves comment. The evaluated checkpoint was not the most accurate candidate seen during training; candidates with better average scores were discarded because they violated a safety constraint. Accepting this trade openly, and encoding it in the selection procedure rather than in the narrative, is in our view a practice worth adopting for learned causal systems in general.

\subsection{Limitations}\label{sec:discussion-limitations}

The study has clear limitations, and the assessment was designed to expose rather than obscure them. First, the free-form neural components are not yet pulling their weight: the gated residual never improved the compiled estimate, and the posterior over causal worlds remained uniform, so two of the architecturally central components currently contribute safety but no accuracy. Second, routing is diffuse; the router keeps all experts active instead of committing to the best one, leaving measurable headroom unused in the threshold cell. Third, variable-order equivariance is imperfect: reordering columns, which should not matter, shifts the estimate noticeably. Fourth, generalization collapses on the one held-out family that is qualitatively unlike the training distribution, which bounds how far the synthetic prior can be trusted. Fifth, the implemented scope is the first slice of the design: static tabular effects, observed regimes, and network interference, without temporal changes, latent variables, or identification with partially specified graphs. Sixth, and most importantly, all evidence in this paper is synthetic. The locked test bank is generated by the same kind of simulator as the training data, so the reported accuracy is an upper bound on what should be expected on real data, where the prior is never exactly right.

\subsection{What a Causal Foundation Model Cannot Solve}\label{sec:discussion-cannot}

Some limits are not engineering debts but mathematical facts, and no amount of pretraining removes them. Hidden confounding cannot be overcome from the same observational data without additional assumptions, instruments, or experiments. No model can estimate a contrast in a region where no comparable data exist. And when several causal structures explain the observed data equally well, the direction of an edge inside that equivalence class is not recoverable from the data alone. A foundation model does not eliminate causal assumptions; it \emph{moves} them into the pretraining distribution. This relocation has a real benefit, because one explicit, versioned, and stress-tested prior replaces thousands of implicit per-analysis choices, but it makes the prior part of the scientific claim. It should be published, criticized, and revised like any other assumption.

\subsection{Future Work}\label{sec:discussion-future}

The findings define a concrete agenda. On the current scope, the priorities are sharper episode-level risk prediction for the router, world particles that actually specialize, and full variable-order equivariance; RQ5 gives each of these a measurable target. On scope, the next extensions are temporal mechanism changes, latent-variable structure, and identification with partially specified graphs, together with sensitivity bounds so that near-violations of assumptions yield widened intervals rather than refusals. On evidence, the essential step is leaving the synthetic world: evaluation on semi-synthetic benchmarks built from real covariate distributions, and on real datasets with randomized or quasi-experimental ground truth. Rich operational event data, for example from business processes and inventory systems, offer an attractive application domain, because they provide the temporal, relational, and interventional structure that the causal episode format is designed to carry.

\section{Conclusions}\label{sec:conclusion}

This paper introduced CWFM, a foundation model for causal inference that treats reliability as a design requirement rather than a hoped-for property. Given a dataset and a formally specified causal question, CWFM selects and combines classical estimators through a learned router, checks identification and data support with deterministic gates before producing any estimate, reports only conformally calibrated uncertainty, and refuses, with a stated reason, the questions that cannot be answered. On a locked synthetic benchmark, this single pretrained model matched the accuracy of the best task-specific estimator in every setting without knowing which setting it was in, kept its intervals near nominal coverage, and answered none of the 120 queries that should be refused, while every baseline answered all of them. The analysis of where these gains come from is equally clear: they are due to the query-correct estimator library, the risk-based routing, and the formal safety logic, not to the free-form neural components, whose contribution remains an open opportunity rather than a demonstrated fact.

We close with the test that we believe should define success for this line of research. A causal foundation model that detects an effect under hidden confounding in every run, while its estimate is badly biased and its intervals never contain the truth, has not advanced causal inference; it has automated false confidence. The measure of progress is therefore not only how accurately a model answers, but whether it knows what it cannot know: whether it separates identified from unidentified questions, supported from unsupported contrasts, and calibrated confidence from mere fluency. CWFM is designed, trained, and selected so that when it fails, it fails safely, and the experiments show that this behavior can be obtained without giving up accuracy on the questions that can be answered. We hope this standard, answer well and refuse well, becomes the default acceptance test for foundation models that claim to reason about cause and effect.
